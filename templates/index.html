About the Rice Type Classification Model

This model is built using a Convolutional Neural Network and trained on labelled images of rice. It takes an image of a rice grain as input and predicts the type of rice.

  • Rice Types: The model classifies 5 different rice types.
  • Dataset: The labelled image dataset was sourced from Kaggle.
  • Architecture: The model uses MobileNetV2 with transfer learning.
